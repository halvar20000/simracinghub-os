# Branding assets

Source assets for SimRacing Hub OS visual identity. These are applied to the
image during the Phase 6 build.

Planned contents:

- `logo.svg` — SimRacing Hub OS logo (can reuse / adapt the website logo).
- `wallpaper-*.png` — desktop wallpapers (light and dark).
- `plymouth/` — boot splash theme.
- `gdm-background.png` — login screen background.

Until Phase 6 these are placeholders; the build script does not yet copy them.
